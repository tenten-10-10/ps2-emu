# PS2 Emu 0.1.0 — preparation draft

> **UNPUBLISHED PREPARATION DRAFT — DO NOT PUBLISH.** No launcher binary is
> attached yet. The source is public, but all four downloads remain blocked
> until the exact files have passed platform signing, clean-machine,
> real-hardware, checksum, and owner review gates.

Public source: https://github.com/tenten-10-10/ps2-emu

Permanent multilingual teaser: https://tenten-10-10.github.io/ps2-emu/

The completed draft must contain exactly these four signed launchers, plus the
release record and checksums generated from the same reviewed source revision:

- macOS 14+ for Apple silicon (`arm64`)
- macOS 14+ for Intel (`x86_64`)
- Windows 11 x64 (`x64`)
- Windows 11 on Arm (native ARM64 launcher; separate x64 Play! process through
  Windows 11 emulation)

PS2 Emu never bundles or downloads Play!, a BIOS, commercial games, encryption
keys, or copyrighted game artwork in these public candidates. The sole playable
fixture is the separately licensed, hash-pinned PS2SDK Cube Demo with its exact
source and required notices. Ko-fi and all binary download buttons
remain disabled while this draft is incomplete.
